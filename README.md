# 📊 Data Analytics & Visualization Portfolio

Welcome to my **Data Analytics & Visualization Portfolio**, a collection of practical projects focused on transforming raw data into meaningful insights through **data cleaning, exploratory data analysis, visualization, business analytics, and interactive dashboard development**. The repository includes projects developed using **Python and Power BI**, demonstrating skills in **Pandas, NumPy, Matplotlib, Seaborn, Plotly, Power Query, DAX, data visualization, KPI analysis, and dashboard development**. Each project includes its relevant datasets, analysis files, visualizations, and project documentation.
