# 🏦 Bank Customer Data Analysis

## 📌 Project Overview

This project focuses on analyzing bank customer data to understand customer demographics, financial behavior, and account-related patterns using exploratory data analysis (EDA).

## 🎯 Objectives

* Analyze customer demographics
* Study account balance distribution
* Explore job and education categories
* Understand age and balance relationships
* Visualize customer segmentation patterns

## 📊 Analysis Performed

### Customer Overview

* Age Distribution Analysis
* Account Balance Distribution
* Job Category Analysis
* Marital Status Distribution

### Customer Demographics

* Education Level Analysis
* Age vs Balance Relationship
* Customer Profile Exploration

### Data Visualization

* Histograms
* Boxplots
* Countplots
* Scatterplots
* Distribution Analysis

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📂 Project File

* `Bank_Customer_Data_Analysis.ipynb`

## 📈 Key Outcome

The project provides insights into customer behavior, financial patterns, and demographic characteristics to support data-driven banking decisions.
